1. The project includes the decade counter design using open source tools.
2. This is the first attempt to push a RTL code through a complete RTL to GDS flow.
3. Icarus Verilog is used to write the verilog code, GTKWave for viewing the output waveforms (simulation) and Yosys for logic synthesis.
4. Currently used the OpenLane for the complete automated backend (physical design) flow and Magic for viewing the layout.
5. Approach for using OpenROAD for the customized Physical design flow in future.
